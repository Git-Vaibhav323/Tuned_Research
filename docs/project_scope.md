# ResearchPilot — Project Scope

**Status:** Foundation scope freeze

---

## 1. Product Statement

ResearchPilot is a data science and research intelligence project that first builds a documented dataset and predictive modeling workflow, then adds fine-tuning, RAG, and a dashboard for researcher-facing assistance.

---

## 2. In Scope

### Phase 1

- Dataset collection and documentation  
- Cleaning, preprocessing, validation  
- Exploratory data analysis and visualization  

### Phase 2

- Feature engineering  
- Multiple ML/DL algorithms  
- Evaluation metrics and comparative analysis  

### Phase 3

- Fine-tuning / PEFT  
- RAG pipeline  
- Interactive dashboard  
- Four research assistant modules  

---

## 3. Out of Scope (for now)

| Area | Notes |
|------|-------|
| Full automated literature review | Beyond Gap Finder inputs |
| Clinical / legal decision support | Never |
| Mobile native apps | Deferred |
| Production multi-user auth | Deferred |
| Paywalled corpus scraping | Not allowed |

---

## 4. Foundation Includes / Excludes

**Included:** folders, README, docs, configs, script scaffolds, notebook folders, requirements list  

**Excluded:** real datasets, trained models, live RAG, running APIs/UI  

---

## 5. Success Criteria

1. Phase 1 delivers a clean, documented dataset with EDA.  
2. Phase 2 delivers fair ML comparison and a justified model choice.  
3. Phase 3 delivers fine-tuning/RAG-backed assistant modules in a dashboard.  
4. Evaluation separates data quality, predictive performance, and assistant quality.
