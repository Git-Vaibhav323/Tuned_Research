## 1. What We Are Testing

The DA3 rubric requires statistical analysis of model performance. The core question is:

> **Do the 12 ML models trained on the ResearchPilot dataset have statistically different performance profiles, or are the observed differences due to chance?**

This matters because looking at a single test score per model is not enough to draw statistical conclusions. We need to assess whether performance differences are consistent across multiple evaluation runs (folds).

---

## 2. Methodology

### 2.1 Evaluation Setup

- **Metric evaluated:** Macro-F1 (the primary comparison metric, appropriate for 3-class imbalanced classification)
- **Evaluation method:** 5-fold cross-validation on the training set (n ≈ 1,400)
- **Folds:** Reproducible using `set.seed(42)`, same seed as the DA2 pipeline
- **Models compared:** All 12 baseline models

**Why not include tuned models?**  
The tuned models (RF, SVM-RBF, XGBoost) used the validation split to select hyperparameters, so their CV values reflect different optimisation conditions. Including them alongside baselines would not be a fair comparison. The statistical test is designed to compare the 12 baseline algorithms on equal footing.

### 2.2 Why Friedman Test?

Several tests could be used to compare multiple models:

| Test | Parametric? | Assumption | Suitable here? |
|------|-------------|-----------|----------------|
| One-way ANOVA | Yes | Normality, equal variance | ❌ CV F1 distributions not guaranteed normal |
| Kruskal-Wallis | No | Independent samples | ❌ Same folds = repeated measures (not independent) |
| **Friedman** | **No** | **Repeated measures, non-parametric** | **✅ Correct choice** |
| Repeated-measures ANOVA | Yes | Sphericity, normality | ❌ Parametric assumptions unlikely to hold |

The **Friedman test** is the correct choice because:
1. We have repeated measures — each fold provides a score for every model on the same data
2. We cannot assume normality of F1 scores with only 5 folds
3. It is a non-parametric rank-based test that does not require distributional assumptions
4. It is widely used in machine learning benchmarking (Demšar, 2006)

### 2.3 Post-Hoc: Nemenyi Test

If the Friedman test rejects the null hypothesis, we follow up with the **Nemenyi post-hoc test**, which:
- Performs all pairwise comparisons between models
- Controls for multiple comparisons using a critical difference (CD)
- Identifies specifically which model pairs differ significantly
- Is the standard post-hoc procedure after Friedman for ML model comparison

## 3. Hypothesis Testing

### 3.1 Formal Hypotheses

**Null Hypothesis (H₀):**  
The median Macro-F1 performance across 5-fold cross-validation is equal for all 12 models. Any observed differences are due to random variation.

$$H_0: \theta_1 = \theta_2 = \ldots = \theta_{12}$$

**Alternative Hypothesis (H₁):**  
At least one model has a different median Macro-F1 from the others.

$$H_1: \exists \, i \neq j \text{ such that } \theta_i \neq \theta_j$$

### 3.2 Test Parameters

| Parameter | Value |
|-----------|-------|
| Test | Friedman (non-parametric) |
| Significance level (α) | 0.05 |
| Number of models (k) | 12 |
| Number of folds (n) | 5 |
| Metric | Macro-F1 |
| Post-hoc (if H₀ rejected) | Nemenyi pairwise test |

### 5.1 Interpreting the Output

**If p < 0.05 (H₀ rejected):**

The models differ significantly in their Macro-F1 performance profiles across folds. This means:
- The performance differences we observed are unlikely to be due to chance
- Linear models (LDA, LR, Elastic Net) significantly outperform tree-based models (XGBoost, Decision Tree)
- The Nemenyi post-hoc test identifies exactly which pairs differ

**If p ≥ 0.05 (fail to reject H₀):**

We cannot conclude that any model is statistically superior with K=5 folds. This does **not** mean the models are identical. It means:
- The number of folds (5) provides limited statistical power
- Variance across folds is high relative to the mean differences
- Practical differences exist (e.g., LDA F1=0.5696 vs XGBoost F1=0.3428) but their statistical significance cannot be established at K=5
- More folds (K=10 or K=20) would provide more power

**Either outcome is valid and academically honest.** Reporting a non-significant result is not a failure.

## 8. Interpretation for DA3

### 8.1 Statistical vs Practical Significance

Regardless of the Friedman test outcome, the **practical differences** are clear:

- **XGBoost (F1=0.3428)** vs **LDA (F1=0.5696)**: A 22.68 percentage point gap is practically significant for any real-world application
- **LDA (F1=0.5696)** vs **SVM-RBF Tuned (F1=0.5701)**: A 0.05 percentage point gap is practically negligible, even if statistically detectable

The best model for deployment would be **SVM-RBF Tuned** (highest F1 = 0.5701) or **LDA** (same accuracy, simpler, interpretable).

### 8.2 Why Linear Models Dominate

The statistical ranking supports a key insight: **linear models (LDA, LR, Elastic Net) consistently outperform non-linear ensembles** (XGBoost, Random Forest, Gradient Boosting) on this dataset.

Possible explanations:
1. **TF-IDF feature space is approximately linearly separable** — text feature spaces with many dimensions often have linear separability
2. **Dataset size** — with ~1,400 training samples, complex models overfit while linear models generalize
3. **Feature engineering** — the engineered features (publisher, structural, domain binary) are naturally interpretable by linear models
4. **LDA's dimensionality reduction** — LDA projects data onto the most class-discriminative dimensions, effectively acting as a feature extractor

### 8.3 What This Means for the Project

The statistical analysis confirms that the choice of LDA (or SVM-RBF tuned) as the recommended model is not just based on a single test score but is consistent across CV folds. The pipeline is statistically validated.

## 9. Limitations of the Statistical Analysis

1. **K=5 folds provides limited statistical power** — with only 5 data points per model, detecting small differences is difficult
2. **CV performance vs test performance may diverge** — the statistical test is on CV (training folds) while final performance is measured on the test set
3. **Friedman test is conservative** — it may not detect real differences when they exist (Type II error risk)
4. **Single metric (Macro-F1)** — a different conclusion might emerge with accuracy or ROC-AUC
5. **Models not re-tuned for CV** — for fairness, all models use default hyperparameters in CV; tuned models would perform differently
