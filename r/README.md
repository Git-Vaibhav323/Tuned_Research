# R Analysis and Visualization

This directory is reserved for DA1 R work.

- `scripts/` — reproducible R or R Markdown analysis
- `visualizations/` — exported R figures when they are not placed in `reports/figures/`

Planned packages include `tidyverse`, `ggplot2`, `janitor`, `skimr`, and `rmarkdown`. R dependencies will be documented separately from Python dependencies once DA1 begins.

R scripts must read the canonical processed dataset from `data/processed/`, state their input/output paths, and include interpretations for the visualizations they generate.
