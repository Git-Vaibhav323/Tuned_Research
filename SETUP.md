# ResearchPilot — Setup Guide

Complete setup instructions for Windows. For a faster overview see `docs/RAG_SETUP_WINDOWS.md`.

---

## Requirements

| Tool | Version | Install |
|------|---------|---------|
| Python | 3.12 | https://python.org |
| R | 4.6+ | https://cran.r-project.org |
| Ollama | latest | https://ollama.com |
| Git | any | https://git-scm.com |

---

## Step 1 — Clone the repo

```powershell
git clone https://github.com/Git-Vaibhav323/Tuned_Research.git
cd Tuned_Research
```

---

## Step 2 — Python dependencies

```powershell
py -3.12 -m pip install -r requirements.txt
```

If you hit CUDA issues with torch:

```powershell
py -3.12 -m pip install torch --index-url https://download.pytorch.org/whl/cu121
```

---

## Step 3 — R packages

Open RStudio, set working directory, then run:

```r
setwd("E:/Tuned_Research")
source("ml/r_pipeline/00_enriched_features.R")  # installs required packages
```

Or install manually:

```r
install.packages(c(
  "shiny", "plotly", "dplyr", "tidyr", "readr", "DT",
  "ggplot2", "scales", "forcats", "patchwork",
  "caret", "randomForest", "e1071", "xgboost",
  "RSQLite", "DBI", "NSM3"
))
```

---

## Step 4 — Environment variables

```powershell
Copy-Item .env.example .env
```

Edit `.env` with your values — at minimum set `OLLAMA_MODEL` to match what `ollama list` shows.

---

## Step 5 — Ollama model

```powershell
# Check what models you have
ollama list

# If researchpilot is not listed, pull the base model
ollama pull qwen2.5:1.5b
```

If you have the fine-tuned GGUF file, register it:

```powershell
# From the ollama/ folder
ollama create researchpilot -f ollama/Modelfile
```

---

## Step 6 — Build the vector index

```powershell
cd E:\Tuned_Research
py -3.12 -m streamlit run streamlit_app/app.py
```

Go to **⚙️ Index Management** → click **Index full corpus**. Takes about 3 minutes. The index persists at `data/rag_vector_store/` — you only need to do this once.

---

## Step 7 — Verify everything works

```powershell
# Test the RAG pipeline end-to-end
py -3.12 test_rag_cli.py

# Run the full evaluation suite
py -3.12 rag_evaluation.py
```

Expected output: 39/40 PASS (1 HUMAN-REVIEW for answer quality).

```r
setwd("E:/Tuned_Research")

```

## Troubleshooting

**Ollama not connecting**
```powershell
# Start Ollama manually
ollama serve
# In another terminal, check it responds
curl http://localhost:11434/api/tags
```

**Streamlit crashes on startup**
```powershell
# Pre-load the embedding model first
py -3.12 run_app.py
```

**R packages missing**
```r
# Install the full list
install.packages("pak")
pak::pkg_install(readLines("ml/r_pipeline/r_packages.txt"))
```

**Index is empty after indexing**
- Check `data/rag_vector_store/` exists and has files
- Check `data/final/final_dataset.csv` exists
- Re-run indexing from the UI

## Data files (not in git)

These are generated by the pipeline and ignored by git:

| Path | Contents | How to regenerate |
|------|----------|-------------------|
| `data/final/` | Locked 2,000-paper corpus CSV | Run `ml/python_pipeline/collect_data.py` |
| `data/ml/` | Feature matrices | Run `ml/python_pipeline/02_build_ml_features.py` |
| `data/ml_r/` | R model objects | Run `ml/r_pipeline/05_ml_models_v2.R` |
| `data/rag_vector_store/` | ChromaDB index | Build from UI — Index Management |
| `models/checkpoints/` | Saved .joblib models | Run `ml/python_pipeline/04_train_models.py` |
| `database/*.db` | SQLite databases | Run `ml/r_pipeline/03_database_setup.R` |
