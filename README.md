# ResearchPilot

A fully local AI research assistant built over 2,000 OpenAlex AI/ML papers.
Ask natural language questions, get grounded answers with citations, compare papers,
find research gaps — all running on your own machine with no cloud API.

Ships with a React + FastAPI web UI, an R Shiny analytics dashboard,
and a complete ML classification pipeline.

---

## What it does

| Feature | Description |
|---------|-------------|
| RAG Research Chat | Ask questions about 2,000 indexed papers — every answer cites the source |
| Paper Analysis | Upload a PDF or paste text — summarise, ask questions, add to index |
| Compare Papers | Select 2–4 indexed papers and compare side-by-side |
| Research Gaps | Find candidate gaps based on retrieved literature |
| Source Inspector | See exactly which passages were retrieved and their relevance scores |
| Browse Papers | Search and filter all 2,000 papers by keyword, OA status, or year |
| Project Stats | ML leaderboard, Friedman test results, RAG metrics — all verified numbers |
| Index Management | Build, inspect, and reset the vector index |
| R Shiny Dashboard | Interactive model comparison, confusion matrix, ROC curves, feature importance |
| 100% Offline | No OpenAI, no cloud APIs, no data leaves your machine |

## Quick Start

### Requirements

- Python 3.12
- Node.js 18+
- R 4.6+
- [Ollama](https://ollama.com) with the model loaded

### 1. Install Python dependencies

```powershell
cd E:\Tuned_Research
py -3.12 -m pip install -r requirements.txt
```

### 2. Set up environment

```powershell
Copy-Item .env.example .env
```

Edit `.env` — make sure `OLLAMA_MODEL` matches what `ollama list` shows.

### 3. Start the React frontend (recommended)

Open two terminals:

**Terminal 1 — API backend:**
```powershell
cd E:\Tuned_Research
py -3.12 -m uvicorn api.main:app --reload --port 8000
```

**Terminal 2 — React frontend:**
```powershell
cd E:\Tuned_Research\frontend
npm run dev
```

Open **http://localhost:5173**

On first launch go to **⚙️ Index Management** → click **Index corpus** (~3 min).
The index persists at `data/rag_vector_store/` so subsequent launches are instant.

### 4. Alternative: Streamlit UI

```powershell
py -3.12 -m streamlit run streamlit_app/app.py
# or double-click LAUNCH_CHATBOT.bat
```

Opens at **http://localhost:8501**

### 5. R Shiny analytics dashboard

```r
setwd("E:/Tuned_Research")
shiny::runApp("dashboard")
```

## ML Pipeline Results

Trained on 1,399 papers, evaluated on 301 held-out test papers (70/15/15 stratified split).

| Rank | Model | Macro-F1 | Accuracy | ROC-AUC |
|------|-------|----------|----------|---------|
| 1 | SVM-RBF (tuned) | **0.5701** | **57.48%** | — |
| 2 | LDA | 0.5696 | 57.48% | 0.7577 |
| 3 | MLP | 0.5657 | 56.81% | 0.7659 |
| 4 | Logistic Regression | 0.5631 | 56.48% | 0.7565 |
| 5 | Elastic Net | 0.5539 | 55.81% | 0.7584 |
| 12 | XGBoost | 0.3428 | 34.55% | 0.5243 |

Statistical validation: Friedman χ²(11) = 43.46, p = 9×10⁻⁶ — differences are not due to chance.

Top features: `pub_ieee` (Gini 43.78), `pub_mdpi` (38.48) — publisher flags dominate,
confirming OA status is driven by publisher policy, not paper content.

## Configuration

```powershell
Copy-Item .env.example .env
```

Key settings in `rag/config.py`:

```python
OLLAMA_MODEL   = "researchpilot"   # must match `ollama list` exactly
OLLAMA_TIMEOUT = 180               # seconds before generation times out
DEFAULT_TOP_K  = 5                 # chunks retrieved per query
CHUNK_SIZE     = 700               # characters per chunk
```

## API Endpoints

The FastAPI backend exposes these endpoints (docs at **http://localhost:8000/docs**):

| Method | Endpoint | Description |
|--------|----------|-------------|
| GET | `/api/health` | Ollama status + index stats |
